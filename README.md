# ArmorPaint Windows Builds 🎨 - 

Automatic Windows builds of [ArmorPaint](https://github.com/armory3d/armorpaint) - free :3

## Download

**[Get the latest build →](../../releases/latest)**

1. Download the `ArmorPaint-Windows-YYYY-MM-DD.zip` file
2. Unzip it
3. Open the `ArmorPaint` folder and run `ArmorPaint.exe`

It runs **every Sunday at 03:00 UTC**
